So what is Terraform supposed to teach you?

This is the important part.

Terraform's purpose here is not to teach you every Snowflake provider quirk.

It's teaching you:

How do I create and manage the infrastructure required by my data platform using code instead of manually clicking around?

For example:

resource "snowflake_database" "advworks" {
    ...
}

means:

"My database is infrastructure. Its desired configuration belongs in Git."

Same for:

Warehouse
Schemas
Stages
Snowpipes
Storage integrations
Roles
Grants
Notifications
Cloud resources

Eventually you should be able to say in an interview:

"I used Terraform to provision and manage Snowflake infrastructure across environments, while dbt handled transformation logic."

That is the skill we're after.
